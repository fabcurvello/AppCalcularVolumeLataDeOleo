# App Calcular Volume da Lata de Óleo

> Repositório didático: exercício prático de Android nativo com **Java**, desenvolvido e aplicado em sala de aula pelo Prof. Fabricio Curvello.

## Sobre o projeto

Aplicativo que calcula o **volume de uma lata cilíndrica** a partir do raio e da altura (V = π · r² · h).

## Contexto acadêmico

Exercício aplicado em sala de aula, usado como prática guiada com os alunos.

## O que o app faz

- Campos para raio e altura.
- Botão que calcula o volume com `Math.PI` e `Math.pow` e mostra o resultado com um ícone de confirmação.

## Conceitos trabalhados em aula

- Entrada e conversão de dados numéricos
- Uso da classe `Math`
- Atualização de `TextView` e `ImageView`

## Tecnologias

- **Java**
- **Android SDK** (Android Studio)
- **Gradle**
- `minSdk 25` / `compileSdk 32`

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/fabcurvello/AppCalcularVolumeLataDeOleo.git
   ```
2. Abra a pasta no **Android Studio** e aguarde a sincronização do Gradle.
3. Execute em um emulador ou dispositivo físico com Android compatível com a API 25 ou superior.
